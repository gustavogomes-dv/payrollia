# Payroll — Chatbot de Investimentos

Chatbot educacional de investimentos integrado ao WhatsApp, construído com Node.js, PostgreSQL, Redis e IA.

## Funcionalidades
- Análise de perfil de investidor (Suitability CVM)
- Integração com WhatsApp Business API
- Cotações em tempo real via Brapi (B3)
- Motor de IA para educação financeira
- Arquitetura SaaS multi-tenant

## Tecnologias
- Node.js + Express
- PostgreSQL + Redis
- Docker
- Anthropic Claude API
- Meta Cloud API (WhatsApp)
